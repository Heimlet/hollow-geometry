# Аналитика

Подключена Яндекс Метрика: посещения, карта кликов, переходы по ссылкам,
Вебвизор и события интерфейса. Основной счётчик загружается независимо от WebGL.
Отключение или блокировка Метрики не мешает сцене.

## Настройка репозитория

`Settings → Secrets and variables → Actions → Variables → METRICA_COUNTER_ID`.
Это публичный номер счётчика, не секретный токен. Он появляется только в артефакте
публикации: workflow генерирует `analytics-config.js` и `noscript`-пиксель.
OAuth-токены Метрики не нужны и не попадают на сайт. Без переменной аналитика
выключена. Локальная разработка и чужие домены не отправляют события.

## Что собирается

| Событие | Смысл |
| --- | --- |
| `hg_tour_start`, `hg_tour_exit` | Начало и выход из тура |
| `hg_chapter_view` | Открытие главы: автоматически или вручную |
| `hg_chapter_finish` | Глава дошла до конца по таймеру |
| `hg_tour_finish` | Достигнут финал; параметр `all_chapters_finished` отличает полный просмотр от перехода сразу к финалу |
| `hg_tour_pause`, `hg_tour_resume` | Нажатие паузы / продолжения |
| `hg_tour_restart`, `hg_tour_reverse` | Повтор и обратный ход |
| `hg_reading_open`, `hg_reading_close` | Открытие и закрытие справки |
| `hg_camera_interaction` | Начало ручного вращения или зума, с ограничением частоты |
| `hg_lab_open`, `hg_preset_select`, `hg_object_change`, `hg_display_change` | Действия в лаборатории и настройки |
| `hg_panel_toggle`, `hg_ui_click` | Сворачивание панели, возврат камеры, плейлист и знакомство с интерфейсом |
| `hg_time` | Приблизительные секунды в разделе / главе / справке |

Параметры: `section`, `tour`, `chapter`, `chapter_number`, `topic`, `activity`.
Время воспроизведения, паузы и чтения считается отдельно. Отправка — раз в 15 с,
при смене контекста, скрытии вкладки и уходе со страницы. Скрытая вкладка исключена;
после зависания устройства разовый интервал ограничен 30 с. Это время видимой
страницы, а не доказательство внимания человека. Последняя отправка при закрытии
браузера может потеряться; блокировщики также сокращают статистику.

Внутренние переходы регистрируются как виртуальные страницы
`#tour/<тур>/<глава>`, `#reading/<тема>`, `#laboratory`, `#home`. Настоящий адрес
браузера при этом не меняется. Код приложения отправляет только известные ID
и настройки, без содержимого полей ввода. Вебвизор отдельно работает по правилам
и настройкам самого счётчика.

## Где смотреть

События и их параметры отправляются через `params` в ветку `hollow_geometry`:
они доступны в отчётах параметров событий без предварительного создания целей.
Временные значения находятся в `hollow_geometry → hg_time → seconds`; это
добавочные интервалы, их нужно суммировать, а не усреднять значения как длительности
целых посещений. Для времени по главам также полезны виртуальные страницы.

Для конверсионных воронок в интерфейсе Метрики создайте цели типа
**JavaScript-событие** с соответствующими идентификаторами, например
`hg_tour_start`, `hg_tour_finish`, `hg_reading_open`. Приложение уже вызывает
`reachGoal` с этими именами. Цели в аккаунте не создаются публичным кодом счётчика.

Документация: [параметры событий](https://yandex.com/support/metrica/en/reports/event-params),
[reachGoal](https://yandex.com/support/metrica/en/objects/reachgoal),
[виртуальные просмотры hit](https://yandex.com/support/metrica/en/objects/hit).
